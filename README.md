# NEXUS - TLS Process Knowledge Assistant

![NEXUS Banner](https://img.shields.io/badge/NEXUS-TLS%20Assistant-4caf50?style=for-the-badge)
![Status](https://img.shields.io/badge/Status-Ready%20to%20Deploy-success?style=for-the-badge)

## 🌿 Overview

NEXUS is an AI-powered knowledge assistant designed to help IBM TLS (Transaction & Licensing Services) team members quickly find and access internal process documents stored in OneDrive.

## ✨ Features

- **Interactive AI Chat Assistant** - Ask questions and get instant guidance
- **Team-Specific Search** - Select your TLS area for targeted results
- **Direct Document Links** - Access OneDrive documents directly
- **Professional Interface** - Clean, modern design with light green theme
- **Mobile Responsive** - Works on all devices

## 📂 TLS Areas Supported

1. **Sales Support Center**
2. **EMEA BP**
3. **ASEANZK**
4. **EMEA International**

## 🚀 Quick Start

## 💻 Technology Stack

- Pure HTML5
- CSS3 with modern gradients and animations
- Vanilla JavaScript (no dependencies)
- Responsive design
- Self-contained (works offline)

## 🎯 How to Use

1. **Select Your Team** - Click on your TLS area button
2. **Ask Questions** - Type your process-related question
3. **Get Answers** - Receive guidance with document links
4. **Access Documents** - Click links to view full process documents
